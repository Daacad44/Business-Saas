# UX / User Flows

## Business Onboarding
Create account
-> Business information
-> Business type
-> Plan
-> Branch
-> Warehouse
-> Import products
-> Import customers
-> Payment settings
-> WhatsApp connection
-> Notification settings
-> Finish

## Credit Sale
Customer
-> POS
-> Add products
-> Select Credit
-> Set/confirm due date
-> Complete sale
-> Invoice created
-> Outstanding balance created
-> Reminder schedule created

## Payment
Customer
-> Outstanding debt
-> Record payment
-> Allocate payment
-> Recalculate balance
-> If balance = 0, mark PAID
-> Receipt
-> Optional WhatsApp confirmation

## Inventory
Purchase received
-> Stock increases
-> Stock movement created
-> Low-stock status recalculated

Sale completed
-> Stock decreases
-> Stock movement created
-> Low-stock automation evaluated
